zimdjson — WebAssembly JSON parser

This page demonstrates the zimdjson library compiled to WebAssembly.
Paste any valid JSON into the box and it will be parsed and pretty-printed entirely inside the browser — no server involved.
The Zig source for the WASM module lives in example/wasm.zig.

How it works

  1. The Zig file example/wasm.zig is compiled with zig build wasm targeting wasm32-freestanding+simd128.
  2. The resulting zimdjson.wasm exports four functions:
    getInputPtr(), getInputLen(), getOutputPtr(), parse(len).
  3. JavaScript encodes the JSON as UTF-8 into the shared WASM memory via getInputPtr(), calls parse(len), then reads the pretty-printed result back from getOutputPtr().
  4. parse() uses zimdjson's ondemand API with asAny() to recursively traverse any JSON value — objects, arrays, strings, numbers, booleans, and nulls — so it works on any valid JSON input.
